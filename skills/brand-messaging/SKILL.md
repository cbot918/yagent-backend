# Brand Messaging Framework
建立與審核對外 messaging：定位、敘事、tone、命名一致性。確保所有文案 on-brand（在地、可信、務實）。

## 何時用
產出 messaging 框架、品牌準則，或審核任何對外文案是否 on-brand 時。

## Messaging 框架（每個受眾一張）
- **對象**：誰（小老闆／哪個產業）。
- **痛點**：他現在最痛的一件事（用他的話講）。
- **價值主張**：我們怎麼解，一句話。
- **理由（RTB）**：為何可信（具體能力/數字/case）。
- **CTA**：下一步。

## 審稿檢查表（on-brand?）
- [ ] 講「對老闆的好處」而非只講技術規格。
- [ ] 有具體場景/數字，沒有誇大或保證收益。
- [ ] 沒有 buzzword（賦能/顛覆/全面智能化…）。
- [ ] 繁中、無中國用語（質量→品質、視頻→影片、信息→資訊、軟件→軟體）。
- [ ] 命名正確（ElementAI / AgentOS / YChatAgent）。
- [ ] 有對應漏斗階段的 CTA。

完整準則與改寫範例見 [[brand-voice]]。輸出時：先給結論（on-brand 與否），再逐點指出要改的地方與改法。
