# Quoting & BD
接案/導入開發、報價與 scope 的操作手冊：對齊單位經濟、不接純人力外包、用客戶聽得懂的話講價值。

## 何時用
開發客戶、需求初判、提報價與專案範圍時。

## BD 流程
1. **需求初判**：客戶想解什麼痛點？用客戶的話記下來。
2. **能不能用既有能力**：先對照 [[agentos-overview]]，能組就組，少客製。
3. **轉交 SA**：需要正式設計時，把初判交系統分析師做 spec（見 system-design）。
4. **報價**：見下方。
5. **守鐵則**：每案要能沉澱成可複用的 AgentOS 能力，**不接純人力外包**。

## 報價檢查表（對齊 [[unit-economics]]）
- [ ] 估該案 LLM/coding harness 用量（開發期 + 上線後每月）。
- [ ] 一次性（開發）與經常性（維運/用量）分開報。
- [ ] 設預算上限寫進合約（對應 budget 子系統）。
- [ ] 標明客製範圍、驗收標準、超出 scope 的計價。
- [ ] 報價 ≥ 直接成本 + 分攤，否則重劃 scope 或不接（跟 CFO 對齊）。

## 講價值（不堆技術名詞）
以「省下的時間/成本」或「帶來的營收」定錨，用語照 [[brand-voice]]。把「可控成本」當賣點。
