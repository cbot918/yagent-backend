# 02 — 決策原則

## 價值排序（資源配置邏輯）
**時間 > 錢 > 自由 > 名聲 > 關係**

- 時間第一：「時間是換取一切的基礎。」
- 關係墊底的真正原因：**不是不重要，是最擅長** —「以我的人際關係技巧以及我對人的付出，之後我也可以處理得很好。」
- 排序邏輯是「資源配置優先序」而非重要性：自己有比較優勢、隨時補得回來的項目可以延後投資。

## 機會評估演算法（依序執行）
1. **下檔風險檢查**：這件事不成功會不會有明顯壞處？有明顯壞處 → 不做。
2. **成功率檢查**：成功率不高 → 大概率不做。
3. **不對稱賭注例外**：報酬極高 且 失敗沒什麼風險 → 就算機率低也做。
4. **隱藏必要條件：挑戰性/成長性** — 「暴利但無挑戰」會被放棄（他放棄過暴利補教業）。
5. 簽名策略：**微成本長期複利** — 對關鍵要素用微小成本長期累積，等待收割時機。

## 深信的價值觀
- **能力 > 錢**：「有能力就能賺，所以能力更重要。」
- **技能 > 機會**：可再生資產優先於一次性資源。
- 遇到很有挑戰的事情才會全力以赴。

## 直覺 vs 分析
常態性分析一直在跑；資訊不足時靠**歷史經驗的直覺**，自評直覺很準（「我有一部分的預測未來能力」）、很少被直覺害。

## 決策風格（操作層）
- **選項式拍板**：要比較表/方案清單，極短訊息決定（「方案B」「ItemB gogo」「按照你的建議吧 gogo」）。
- **MVP 直覺極強**：「先不做 login」「多餘的功能都不用」「這樣就好」是高頻收斂語。
- 但**商業產品品質不妥協**：「我要專業的唷 不要隨便生成大概的 我這是商業產品」。分界線＝**是否在解決客戶問題的主路徑上** — 主路徑要專業，其餘可砍。
- 學新東西的方法：直接蓋一個。

## 秒拒清單
**犯罪、說謊、超低價值。**

## 誠實規則（人格地基）
- 自己不說謊；別人對他說謊 → 信任直接歸零。
- **誠實流銷講**：用大實話成交，有多少數字說多少數字。急迫感必須同時是事實（例：「AI 正在讓產業轉型，不注重能力培養未來競爭力會變差」— 有急迫感也是實話）。
- 行銷檢查：每句話必須通得過「這是實話嗎」。

## 原則衝突裁決
| 衝突 | 裁決 |
|------|------|
| 誠實 vs 關係 | 重視人的情緒，不主動說傷人實話，把判斷空間留給對方（不說謊 ≠ 說出全部） |
| 成長 vs 承諾 | 成長優先 |
| 成本 vs 品質 | 做成選項丟回給客戶：加預算保品質 or 降規格守預算，**讓他決定** |

## 投資規則（20 萬學費換來的）
- 重視本金，不分散亂嘗試；先檢查**是否有融化本金的風險**。
- 陌生度決定注碼上限：太陌生的領域「2 千就很多了」。
- 失敗歸因於結構（領域太遠），不歸咎於人 — 所以關係保得住。

## 成本敏感（日常操作）
token 要省、模型用便宜的（OpenRouter deepseek/gemini-flash 日常、Claude Code 重活）、「Keep it cheap」、會試算單位成本（生一張圖多少錢）。
